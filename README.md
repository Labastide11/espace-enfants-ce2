# Espace Enfants CE2 — V0.18 — Entraide sur une page unique

## Accueil
Les deux cartes séparées « Je peux aider » et « J’ai besoin d’aide » sont supprimées.

Elles sont remplacées par le bandeau validé « Entraide avec Nino ».
Un clic sur ce bandeau ouvre `entraide.html`.

Les deux autres rubriques restent sous le bandeau :
- Je ne sais pas quoi faire
- Mon métier

## Nouvelle page entraide
La page présente 3 colonnes visibles simultanément :
- 📘 Je travaille
- 🤝 Je peux aider
- 🙋 J’ai besoin d’aide

Au départ, tous les élèves sont dans « Je travaille ».

Quand un enfant clique sur sa photo, une petite fenêtre lui propose les 3 destinations.
Sa photo se déplace ensuite dans la colonne choisie.

Les élèves de « Je peux aider » ont un badge vert sur leur photo.
Les élèves de « J’ai besoin d’aide » ont un badge orange sur leur photo.
